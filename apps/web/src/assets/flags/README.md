# Country flags

The 249 flags of the ISO 3166-1 countries, in the 4:3 format, from [flag-icons](https://github.com/lipis/flag-icons) 7.6.0, copied unmodified. Each file is named after the country's alpha-2 code in lowercase, the same codes as `COUNTRIES` in `packages/@ligungi/protocol/src/profile.ts`.

flag-icons is licensed under the MIT License, which allows bundling the files with ligungi (AGPL-3.0-or-later). The full license is in [LICENSE](LICENSE).

The site loads each flag as its own file (`src/flags.ts`), only when a page shows it.
