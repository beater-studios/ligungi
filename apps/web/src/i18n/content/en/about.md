ligungi is a free platform to play Gungi (軍儀), the board game from HUNTER×HUNTER, online with the official rules published by Universal Music (2022). No ads, no account required, and the code is open.

It is made by [Beater Studios](studio) and inspired by lichess.org: the interface reuses the look of lila, lichess's open source code.
