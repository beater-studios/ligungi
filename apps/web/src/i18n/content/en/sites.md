ligungi is built on [lila](lila), the open source code of lichess. Other sites grew from the same base, each for one game. If you like ligungi, they are worth a visit:

- [lichess.org](lichess): chess. Where it all started, free, without ads and open source.
- [lishogi.org](lishogi): shogi, Japanese chess, on a version of lichess rewritten for it.
- [lidraughts.org](lidraughts): international draughts and its variants, on the same base as lichess.
- [PlayStrategy](playstrategy): over 40 strategy games, such as chess, go, draughts, shogi, othello and backgammon, built on lila.

## Other board games

- [libaduk.com](libaduk): go (baduk), to play and learn, with lessons and a game library.
