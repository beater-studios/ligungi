# References

Material used to write [docs/rules.md](../docs/rules.md). Only this index is versioned: everything else is third-party content (repositories, saved pages, PDFs) and stays out of git.

## Official rules (2022, Universal Music)

| File | What it is | Use |
|---|---|---|
| `komugi-gungi-engine/gungi_rulebook_jp.pdf` | Official rulebook in Japanese (軍儀解説書) | Primary source |
| [Official FAQ](https://www.universal-music.co.jp/other/hunter-gungi__qa/) (online) | Q1 to Q30, includes an erratum and 7 Archer images | Primary source |
| [English rulebook](https://planetbanatt.net/docs/gungi_rulebook_en.pdf) (online) | Faithful translation of the rulebook | Support |
| `軍儀のルール.html` | 軍儀Web (gungi.2410.dev), a site that states it follows the official rules | Secondary source |
| `komugi-gungi-engine/` | Komugi engine (C++), implements the official rules with some differences | Cross-checking |
| `Learn _ Gungi.html` | Rules page of the current gungi.io | How a platform handles the rules |
